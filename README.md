# BillingEase

Your whole business in three numbers: **Coming in − Going out = Yours to keep.**

| Folder | What it is |
|---|---|
| [`web/`](web/) | The app: Next.js + TypeScript + PostgreSQL with a double-entry ledger underneath the three numbers. Start here. See [`web/README.md`](web/README.md). |
| [`prototype/`](prototype/) | The clickable design prototype the app is built from (static HTML, sample data). See [`prototype/README.md`](prototype/README.md). |

Quick start:

```sh
cd web
npm install
npm run dev
# open http://localhost:3000 and create an account
```
